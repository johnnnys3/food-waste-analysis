# Food Waste Inventory Analysis

Individual Excel project from the BLOSSOM data analytics programme.

**Data:** 2025 inventory-system export, 8,200 rows covering 8,000 unique batches across restaurants, supermarkets, cloud kitchens and cafeterias (16 raw fields).

## Files
- `food_waste_.xlsx`: analysis workbook
- `food_waste_.csv`: raw export
- `Food Waste Inventory Analysis Data, Cleaning, Objectives and Recommendations.docx`: data dictionary, cleaning, objectives, recommendations
